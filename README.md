## 📖 О приложении

**Бюджет** — это веб-приложение (PWA) для учёта личных доходов и расходов. Открывается в браузере, ставится на домашний экран как обычное приложение и работает полностью офлайн.

**Никакой регистрации. Никакой рекламы. Никакой отправки данных в интернет.** Все записи хранятся в локальном хранилище браузера на вашем устройстве.

## ✨ Возможности

### 💰 Доходы
- Ввод суммы, выбор категории, дата и необязательное примечание
- Дата регулируется — можно внести запись задним числом
- Список всех доходов с сортировкой по дате (свежие сверху)
- Удаление любой записи одним нажатием

### 💸 Расходы
- Ввод суммы, выбор категории, дата и необязательное примечание
- Дата регулируется — удобно, если забыли внести вчерашнюю покупку
- Список всех расходов с сортировкой по дате
- Удаление любой записи одним нажатием

### 🏷 Категории
- Отдельные списки категорий для доходов и расходов
- Переключатель «Доходы / Расходы» в один тап
- Добавление и удаление категорий
- При удалении категории записи остаются, но помечаются как «Без категории»

### 📊 Статистика
- Фильтр периода: **Месяц** (30 дней), **Год** (365 дней), **Весь** (за всё время)
- Карточка «Итого»: суммарные доходы, расходы и баланс
- Разбивка по категориям — сколько пришло и сколько ушло по каждой
- Список по дням с детализацией каждой операции

### 🎨 Интерфейс
- Тёмная тема, аккуратные скругления, крупные кнопки под палец
- Всё помещается на iPhone без горизонтальной прокрутки
- Поддержка safe-area (вырез, домашний индикатор)

### 💾 Резервное копирование
- Кнопка ⇅ открывает панель бэкапа
- Копирование JSON в буфер обмена, скачивание файлом, загрузка и восстановление
- Данные хранятся в `localStorage` и привязаны к домену — **сохраняйте бэкап время от времени**

## 📥 Установка на iPhone

1. Откройте приложение в **Safari**: 👉 [stuma467.github.io/budget-pwa](https://stuma467.github.io/budget-pwa/)
2. Нажмите **«Поделиться»** → **«На экран Домой»**.
3. Назовите — например, «Бюджет» — и добавьте.

Запускается с домашнего экрана как обычное приложение, без адресной строки Safari. Работает офлайн.

## 📥 Установка на Android

1. Откройте приложение в **Chrome**: 👉 [stuma467.github.io/budget-pwa](https://stuma467.github.io/budget-pwa/)
2. Меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).

## ⚠️ Важно про данные

Данные хранятся **только в вашем браузере**, в `localStorage`. Это значит:

- ✅ Никто, кроме вас, их не видит
- ⚠️ Если очистить историю Safari/Chrome — **данные пропадут**
- ⚠️ Если поменять домен приложения или открыть по другой ссылке — это уже другое хранилище

**Решение:** раз в неделю (или после крупных операций) нажимайте **⇅** в шапке и сохраняйте бэкап — в «Заметки» текстом или файлом. Восстановление занимает 10 секунд.

## 🔄 Обновление приложения

Обновить файлы на GitHub можно в любой момент — **данные в бюджете при этом не потеряются**, потому что они хранятся в телефоне, а не на сервере.

Чтобы не потерять данные, никогда не меняйте:
- ❌ название репозитория и URL сайта
- ❌ ключ хранилища `'budget_pwa_v1'` в `app.js`

## 🛠 Технологии

- **Vanilla JavaScript** — без сборщиков и зависимостей
- **CSS Flexbox** — адаптивная вёрстка под мобильные экраны
- **localStorage** — хранение записей на устройстве
- **Service Worker** (cache-first) — офлайн-режим и мгновенная загрузка
- **Web App Manifest** — установка как PWA с иконкой
- Хостинг: **GitHub Pages**
